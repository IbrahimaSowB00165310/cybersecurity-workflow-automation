# Cybersecurity automation tool

## project description

This project is an automation tool in Cybersecurity combining PowerShell and Python.
The PowerShell script analyses log files to identify suspicious IP addresses.
The Python script retrieves the IP addresses and analysis them with VirusTotal API to determine if they are malicious or suspicious.

## Cybersecurity context

suspicious logs connection analyse is a regular task in Cybersecurity.
This project automate identifying and enrichment suspicious IP addresses in order to help a security analyst to quickly detect potential malicious activities.

## Usage

Lunch the PowerShell script to analyse logs and generate a CSV file, which contains suspicious IP addresses
.\PS-script.ps1

You will be asked to enter the log file path


## Internal workflow

- PowerShell script extract suspicious IP addresses from the log file
   - generate a suspicious csv loggings file
-Python script :
   - read the most recent CSV file
   - delete duplicate
   - query VirusTotal API
   - generate a new CSV file with results

## Output files

- PowerShell script generate a CSV suscicious timestamped logging file containing :
  - Date, time and Ip address
-Python script generate a CSV file timestamped containing:
  - Ip address
  - number of malicious detections
  - number of supecious detections
  - eventual erreurs
